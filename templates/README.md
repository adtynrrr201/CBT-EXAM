# Templates

## Excel siswa
Header wajib: `NIS | Nama Lengkap | Kelas | L/P | Password (opsional) | Tahun Ajaran`
Lihat `contoh-siswa.csv`. Save As `.xlsx` sebelum upload. NIS unik, Kelas harus ada di master.

## Word soal
Save As `.docx`. Format:
```
1. Ibu kota Indonesia ....
   A. Bandung
   B. Jakarta *
   C. Surabaya
   D. Medan
   [Bobot: 10] [Kesulitan: mudah]
```
- `*` di akhir opsi = kunci. PG kompleks boleh >1 `*`.
- `[Uraian]`, `[Isian: ...]`, `[GAMBAR]` didukung. Lihat `Template_Soal_CBT.md`.
